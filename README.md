# Netflix Landing Page Clone

A responsive Netflix landing page clone built using **HTML** and **CSS**. This project replicates the design and layout of the Netflix homepage with a focus on creating a simple yet elegant user interface using basic web technologies.

## Features

- **Responsive Design:** Fully optimized for desktop and mobile devices.
- **Hero Section:** Prominent Netflix banner with a call-to-action button.
- **Content Layout:** Displays sections for featured shows and movies.
- **Footer:** Includes various links and social media icons.

## Technologies Used

- **HTML:** Markup language for structuring the web page.
- **CSS:** Styling the page to match the Netflix landing page design.
